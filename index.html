Course Description

This course introduces principles and applications of databases. Students will study relational database design, learn how to model real-world data, and explore techniques for constructing, populating, and retrieving data. Beyond relational models, students will also gain experience with Python integration, NoSQL databases like MongoDB, and building simple web apps that publish data from databases.

Prerequisites

Introduction to Computer Programming, such as CSCI-UA.0002 or CSCI-UA.0003, with a grade of C or better.

Students who have completed Data Management and Analysis, CSCI-UA.0479, are not eligible.

Learning Objectives

  • Understand common textual data formats: CSV, JSON, XML, HTML.
  • Apply relational database theory: relational model, normalization, and ER diagrams.
  • Program with SQL: writing, optimizing, and managing queries.
  • Use MongoDB as an introduction to NoSQL databases.
  • Integrate Python programs with both SQL and NoSQL databases.
  • Develop simple Python-based, database-driven web applications using Flask.
